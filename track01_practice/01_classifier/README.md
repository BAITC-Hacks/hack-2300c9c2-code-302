# Классификатор обращений

Трек 01 «Агентные системы», упражнение «Классификатор обращений» — репетиция схемы
«поток сообщений → структура → решение», той же, что в голосовых рапортах (упражнение 09).

## Что делает

Читает 5 готовых обращений из `messages.txt` и для каждого печатает:

- категорию: `справка` / `жалоба` / `другое`;
- черновик ответа на русском.

Категория определяется правилами по ключевым словам (без вызова LLM — быстрее и не
требует API-ключа во время демо).

## Как запустить

```bash
cd track01_practice/01_classifier
python classify_messages.py
```

На Windows, если кириллица в консоли выводится «кракозябрами», запускайте с
принудительным UTF-8:

```bash
set PYTHONUTF8=1 && python classify_messages.py
```

## Что получилось

| № | Обращение | Категория |
|---|---|---|
| 1 | Как получить справку о месте учёбы? | справка |
| 2 | В столовой очередь, еда холодная. | жалоба |
| 3 | Хочу записаться на консультацию завтра. | другое |
| 4 | Пропал Wi-Fi в корпусе B. | жалоба |
| 5 | Где парковка для гостей? | справка |

Скрипт отработал за один запуск, без ошибок; на 5 обращений уходит меньше секунды.
