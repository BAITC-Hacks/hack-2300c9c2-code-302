# Классификатор обращений

Трек 01 «Агентные системы», упражнение «Классификатор обращений» — репетиция схемы
«поток сообщений → структура → решение», той же, что в голосовых рапортах (упражнение 09).

## Что делает

Читает 5 готовых обращений из `messages.txt` и для каждого печатает:

- категорию: `справка` / `жалоба` / `другое`;
- черновик ответа на русском.

Категория определяется правилами по ключевым словам (без вызова LLM — быстрее и не
требует API-ключа во время демо).

## Как пользоваться

1. Установите Python 3.11/3.12 (сторонние библиотеки не нужны).
2. Запустите на заготовленных 5 обращениях:
   ```bash
   cd track01_practice/01_classifier
   python classify_messages.py
   ```
3. Чтобы проверить свои обращения — отредактируйте `messages.txt` (одно обращение на
   строку) и запустите скрипт снова, либо укажите другой файл:
   ```bash
   python classify_messages.py my_messages.txt
   ```

Скрипт сам печатает вывод в UTF-8 (`sys.stdout.reconfigure`), поэтому кириллица
корректно отображается в любом терминале Windows/macOS/Linux без дополнительных
переменных окружения.

## Как это работает

Категория определяется правилами по ключевым словам в `COMPLAINT_WORDS` /
`INFO_REQUEST_WORDS` (файл `classify_messages.py`) — без вызова LLM, поэтому не
нужен API-ключ и результат воспроизводится мгновенно. Если совпадений нет —
категория `другое`.

**Ограничение:** правила ловят только слова из списка. Если добавить новую
формулировку жалобы или вопроса (например, «не отвечают» вместо «не работает»),
её нужно вписать в соответствующий список руками.

## Что получилось

| № | Обращение | Категория |
|---|---|---|
| 1 | Как получить справку о месте учёбы? | справка |
| 2 | В столовой очередь, еда холодная. | жалоба |
| 3 | Хочу записаться на консультацию завтра. | другое |
| 4 | Пропал Wi-Fi в корпусе B. | жалоба |
| 5 | Где парковка для гостей? | справка |

Скрипт отработал за один запуск, без ошибок; на 5 обращений уходит меньше секунды.
Дополнительно проверено на 5 сообщениях с другими формулировками — после
расширения списков ключевых слов классификация верна.
