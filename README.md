# hack-2300c9c2-code-302

Командный репозиторий на хакатоне **HackAlem AI** · трек **agentic-AI** · добывающая промышленность.

> Основной конкурсный проект будет писаться здесь с нуля 23 сентября (п. 6.4, 6.8 положения).
> До этого момента в репозитории — только тренировочные упражнения, отмеченные как таковые.

## Идея проекта

Агент, который читает поток показаний датчиков шахты, отсекает шум в тревогах и сам
решает, что делать: какие события критичны, кого уведомить, какое действие предпринять.

Подробности запуска — в README каждого упражнения.

## Как запустить тренировочные скрипты

```bash
git clone https://github.com/BAITC-Hacks/hack-2300c9c2-code-302.git
cd hack-2300c9c2-code-302

# классификатор обращений
cd track01_practice/01_classifier
python classify_messages.py

# фильтр алертов
cd ../02_alert_filter
python filter_alerts.py
```

На Windows, если кириллица в консоли выводится некорректно, запускайте с
`set PYTHONUTF8=1 && python <script>.py`.
